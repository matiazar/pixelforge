# Preguntas: App de generacion de imagenes (Pixelforge)

Fecha: 26/11/2026

Cada pregunta incluye lo que haremos si no hay respuesta. Las marcadas con [clave] son las que mas cambian el trabajo.

## Costos

1. [clave] Antes de generar una imagen, el precio final todavia no se conoce. Que quieren que vea el usuario: un valor aproximado, un rango (minimo y maximo) o solo el maximo posible?
   Si no hay respuesta: rango, con el maximo destacado.
   Respuesta: Precio exacto no es posible: rango.

2. El usuario debe ver solo su precio final, o tambien cuanto cobra el proveedor y cuanto es el recargo del 25%?
   Si no hay respuesta: solo su precio final.
   Respuesta: Solo precio final.

## Uso de la aplicacion

3. [clave] El proveedor permite como maximo 3 imagenes en proceso a la vez, sumando a todos los usuarios. Si alguien pide una cuarta, preferirian que quede en una fila de espera y salga sola, o mostrar un aviso para que lo intente mas tarde?
   Si no hay respuesta: aviso claro para reintentar, sin perder lo que escribio.
   Respuesta: Aviso de que va a la cola.

4. [clave] Cualquier persona puede crear una cuenta en la version publicada, o solo quienes ustedes autoricen? Con registro abierto, un desconocido podria agotar el limite diario del proveedor.
   Si no hay respuesta: registro abierto, con un limite diario por usuario.
   Respuesta: OK al supuesto.

5. Cuando una imagen falla, quieren un boton para volver a intentarlo con los mismos datos?
   Si no hay respuesta: si, lo decide el usuario. No se reintenta solo una imagen que ya fallo.
   Respuesta: Si, boton de reintento.

6. En que idioma tiene que estar la aplicacion?
   Si no hay respuesta: ingles.
   Respuesta: Ingles.

## Extras (solo si se incluyen)

7. Informe para administradores: quien debe tener acceso y en que horario se cuentan los dias?
   Si no hay respuesta: una cuenta de prueba con permiso de administrador, y dias segun horario universal (UTC), igual que el proveedor.
   Respuesta: Ajustes globales del admin, entre ellos la zona horaria.

8. Saldo: para permitir una generacion, alcanza con que el usuario tenga saldo para el valor aproximado, o tiene que cubrir el maximo posible?
   Si no hay respuesta: debe cubrir el maximo posible. Se reserva y luego se devuelve la diferencia.
   Respuesta: OK.

## Entrega

9. [clave] Cuando piden entregar la aplicacion "con algunas generaciones disponibles", se refieren a dejar ejemplos ya hechos en el historial, a que quede margen para que ustedes generen mas, o las dos cosas?
   Si no hay respuesta: las dos cosas.
   Respuesta: Ambas.

10. Como van a ingresar quienes revisen: crean su propia cuenta o prefieren una cuenta de prueba ya preparada?
    Si no hay respuesta: cuenta de prueba, con los datos enviados junto a la entrega.
    Respuesta: OK, cuenta de prueba.

11. Hay una fecha limite de entrega?
    Respuesta: Hoy.
